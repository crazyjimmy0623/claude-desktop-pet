# Deskmates

住在工作列上的像素小夥伴。你寫程式，他在旁邊打字；Claude 在讀檔，他就捧著書看；等你按批准的時候，他會跳起來跟你揮手。

沒在用 AI 也能養。打開「電腦活動」，代表你的角色會看你正在用什麼程式換動作。也可以在夥伴手冊按「＋ 邀請居民」，找最多 6 個角色住進房間，他們會自己看書、喝咖啡、打電動，晚上就去睡覺。

## 做自己的角色

夥伴手冊的「✨ 創角」有三種做法：

- **換裝**：頭、頭髮、身體、配件、顏色一樣一樣挑，懶得想就按 🎲。招募到新角色，他身上的零件（白盔、絨毛玩偶頭、披風…）也會跟著解鎖
- **畫畫**：有人形參考線，也能左右對稱。只畫正面就夠了，走路、呼吸、打瞌睡、開心跳都會自己動；想畫細一點，再補走路、工作、睡覺、開心的姿勢
- **照片**：娃娃、公仔或手繪圖拖進來，會自動去背、縮成像素，再稍微修一下就好

做好按「完成」，自己、居民或 AI 夥伴都能穿。

想送給朋友，就到「💌 朋友」把角色做成角色卡，複製後貼到 LINE 或 Discord。朋友把卡片拖進他的 Deskmates，角色就會進到他的朋友圖鑑，也能請他住進房間。圖被聊天軟體壓過也沒關係，一樣讀得出來。

## 兩種模式

- **工作列**：角色直接站在工作列上。可以拖、可以甩，點一下看狀態，雙擊摸頭
- **房間**：桌面右下角一間等角視角的小屋，可以拖到別的地方

兩邊都有按鈕可以切換：工作列在右下角的小工具列，房間在右上角。

### 蓋房子

房間編輯器有現成的藍圖：街角小店、賽博公寓、湖畔溫室、熱帶海邊小屋、森林溫馨木屋。零件都解鎖、金幣也夠，就能一鍵蓋好。想自己來的話，就用方塊拼：

- 點方塊頂面往上疊，點側面往旁邊接。有磚、草地、木平台、室內、閣樓、玻璃屋和水池
- 樓梯放在高台旁邊的地板上，會自己接上去；旋轉樓梯只要一格就能繞上去
- 樹、竹子、岩石在「植物」裡，沿著外圍種一圈就是背景
- 按「刪除」之後，滑鼠指到的東西會變紅，點下去就拆掉

牆、地基、欄杆和影子會自己長出來。燈光跟著時間變，也能選天氣（雨、雪、櫻花、落葉）。

角色會走去對應的家具，要的話還會爬樓梯：寫程式坐電腦、下指令去伺服器、讀檔翻書櫃、等批准就去按櫃台鈴，睏了就躺沙發或床。

## 角色在演什麼

| 來源 | 會發生什麼 |
|---|---|
| Claude Code hooks | 每個 session 一位夥伴。你送出指令時，你的角色會走過去把話講給他聽 |
| 電腦活動 | 看前景程式：VS Code、Unity 是寫程式，Photoshop、Aseprite 是畫畫，瀏覽器是上網，開 Spotify 就跳舞…對應表可以在設定裡改。離開電腦他就去睡 |
| 番茄鐘 | 專注時倒數，休息時去喝咖啡 |
| 通用 API | 任何程式 POST 到 `http://127.0.0.1:47321/api/event` 都能控制一位夥伴 |
| Codex CLI | `notify = ["curl", "-s", "-m", "1", "http://127.0.0.1:47321/codex", "-H", "Content-Type: application/json", "-d"]` |

隱私：只看前景是哪個程式、你有沒有在動，不記錄打字內容，也不讀視窗裡的東西。資料全部留在你的電腦上。

## 收集

- **金幣**：只能靠工作賺，沒有儲值。AI 跑完回合、番茄鐘、陪伴時間（每 5 分鐘 1 枚）、在同一類程式連續專心 25 分鐘、每日簽到（連續越久給越多）、抓 bug、拆包裹都有。不用 AI 一樣賺得到
- **招募**：10 🪙 抽一次，角色、配件、家具、植物、建材、地板、牆面和更大的地都抽得到。重複的退 3 🪙，十連保底稀有以上
- **蓋房子**：大家都從同一塊 8×8 草地開始，抽到才能換 10×10、12×12。方塊、樓梯、家具、植物都要花錢，拆掉退一半
- **圖鑑、成就、每週戰績卡**：戰績卡可以存成圖片
- **隨機事件**：工具出錯會爬出一隻 bug，長任務做完會送來包裹，context 壓縮時有 UFO 飛過

## 自訂

- 11 種角色、8 種配件，AI session 預設是暴走機器人。傳說角色是我們團隊本人：冷酷吉米（白盔紅披風）、布魯（白色鴨嘴獸）、歐凱（白貓），只能用抽的
- 房間編輯器：擺家具、塗地板、換牆面、調高度
- 自己的素材放進 `%APPDATA%\Deskmates\custom\`：
  - `characters/<名稱>/`：Aseprite 匯出的 PNG + JSON，用 frame tag 命名動作（idle、walk、work、type、command、game、read、wait、done、sleep…）
  - `tiles/`：16x16 PNG，房間編輯器的「自訂地板」可以直接塗

## 開發

```
npm install
npm start              # 啟動
npm run demo           # 播放示範
npm run install-hooks  # 安裝 Claude Code hooks（設定視窗也有按鈕）
npm run preview -- chars out.png   # 輸出角色/家具預覽圖（chars | lineup | minis | anim | fx | iso）
```

啟動參數：`--demo`、`--mode=room|strip`、`--open=settings|guild`。設 `DESKMATES_DEBUG=1` 會印出 hook 事件和視窗 console。

```
src/main/        主程式：actors（角色狀態）、progress（金幣/成就/招募）、fx（隨機事件）、
                 focus（番茄鐘）、activity（前景程式偵測）、server（HTTP）、windows（工作列視窗）、store
src/shared/      主程式和畫面共用：catalog（物品/成就）、sprites（角色）、iso（等角房間與家具）
src/renderer/    strip（工作列）、room（房間 + 編輯器）、settings、guild（夥伴手冊）
```

美術全部用程式畫，沒有外部素材。圖都畫在兩倍細的網格上（角色 64x56、地磚 32x32 細格），不描黑邊，每個部位用自己顏色深一階收邊。角色是兩頭身：大頭、扁臉、豆豆眼。
