# Deskmates

一個住在工作列上的小人。你寫程式，他就打字；Claude 在看檔案，他就看書；Claude 在等你點頭，他就跳起來揮手叫你。

沒在用 AI 也能養。打開「電腦活動」，你的小人就會跟著你正在用的程式換動作。也可以在夥伴手冊按「＋ 邀請居民」，找最多 6 個角色住進房間，他們會自己看書、喝咖啡、打電動，晚上就去睡覺。

## 做自己的角色

夥伴手冊的「✨ 創角」有三種做法：

- **換裝**：頭、頭髮、身體、配件、顏色一樣一樣挑，懶得想就按 🎲。招募到新角色，他身上的零件（白盔、太空頭盔、披風…）也會跟著解鎖
- **畫畫**：有人形參考線，也能左右對稱。只畫正面就夠了，走路、呼吸、打瞌睡、開心跳都會自己動；想畫細一點，再補走路、工作、睡覺、開心的姿勢
- **照片**：娃娃、公仔或手繪圖拖進來，會自動去背、縮成像素，再稍微修一下就好

做好按「完成」，自己、居民或 AI 夥伴都能穿。

想送給朋友，就到「💌 朋友」把角色做成角色卡，複製後貼到 LINE 或 Discord。朋友把卡片拖到他的房間上，角色就會直接搬進去；拖到「💌 朋友」裡則只收進朋友圖鑑。圖被聊天軟體壓過也沒關係，一樣讀得出來。

房子也能分享：在「💌 朋友」按「📸 做成房間卡」，朋友把它拖到房間上就會過來參觀，看完按「🏠 回家」。零件都抽到的話，還能付錢「照著蓋」一間一樣的（現在的房子拆掉退一半）。

## 兩種模式

- **工作列**：角色直接站在工作列上。可以拖、可以甩，點一下看狀態，雙擊摸頭
- **房間**：桌面右下角的一間小房子，可以拖去別的地方

兩邊都有按鈕可以切換：工作列在右下角的小工具列，房間在右上角。

### 蓋房子

編輯房間時有現成的房子可以選：街角小店、賽博公寓、湖畔溫室、熱帶海邊小屋、森林溫馨木屋。零件都解鎖、金幣也夠，就能一鍵蓋好。想自己來的話，就用方塊拼：

- 點方塊頂面往上疊，點側面往旁邊接。有磚、草地、木平台、室內、閣樓、玻璃屋和水池
- 樓梯放在高台旁邊的地板上，會自己接上去；旋轉樓梯只要一格就能繞上去
- 樹、竹子、岩石在「植物」裡，沿著外圍種一圈就是背景
- 按「刪除」之後，滑鼠指到的東西會變紅，點下去就拆掉

牆、地基、欄杆和影子會自己長出來。燈光跟著時間變，也能選天氣（雨、雪、櫻花、落葉）。

角色會走去對應的家具，要的話還會爬樓梯：寫程式坐電腦、下指令去伺服器、讀檔翻書櫃、寫文件去打字機書桌、等批准就去按櫃台鈴，睏了就躺沙發或床。居民閒著會圍著暖桌聊天、去彈吉他或放黑膠唱片。

## 角色在演什麼

| 來源 | 會發生什麼 |
|---|---|
| Claude Code | 每開一個對話，就多一位夥伴。你交代事情時，你的小人會走過去跟他講 |
| 電腦活動 | 看你正在用的程式：VS Code、Unity 是寫程式，Photoshop、Aseprite 是畫畫，瀏覽器是上網，開 Spotify 就跳舞…這些在設定裡都能改。你離開電腦，他就去睡 |
| 番茄鐘 | 專注時倒數，休息時去喝咖啡 |
| 自己寫的程式 | 任何程式 POST 到 `http://127.0.0.1:47321/api/event` 都能控制一位夥伴 |
| Codex CLI | `notify = ["curl", "-s", "-m", "1", "http://127.0.0.1:47321/codex", "-H", "Content-Type: application/json", "-d"]` |

隱私：只看你正在用哪個程式、有沒有在動。不記你打了什麼字，也不看視窗裡的內容。東西全部只存在你自己的電腦。

## 收集

- **金幣**：只能靠用電腦慢慢存，不能花錢買。AI 做完一件事、番茄鐘、開著陪你（每 5 分鐘 1 枚）、同一個程式專心用滿 25 分鐘、每天簽到（連續越多天給越多）、抓 bug、拆包裹都有。不用 AI 也存得到
- **招募**：10 🪙 抽一次，角色、配件、家具、植物、建材、地板、牆面和更大的地都抽得到。抽到重複的退 3 🪙；一次抽 10 個，至少有一個稀有的
- **蓋房子**：大家都從同一塊 8×8 草地開始，抽到才能換 10×10、12×12。方塊、樓梯、家具、植物都要花錢，拆掉退一半
- **圖鑑、成就、每週戰績卡**：戰績卡可以存成圖片給別人看
- **隨機事件**：AI 做事出錯會爬出一隻 bug，AI 忙了很久終於做完，會收到包裹，Claude 整理記憶的時候會有 UFO 飛過

## 自訂

- 9 種角色、8 種配件，AI 夥伴一開始是暴走機器人。傳說角色是我們團隊本人：冷酷吉米（白盔紅披風），只能用抽的
- 房間編輯器：擺家具、塗地板、換牆面、調高度
- 自己的素材放進 `%APPDATA%\Deskmates\custom\`：
  - `characters/<名稱>/`：Aseprite 匯出的 PNG + JSON，用 frame tag 命名動作（idle、walk、work、type、command、game、read、wait、done、sleep…）
  - `tiles/`：16x16 PNG，房間編輯器的「自訂地板」可以直接塗

## 開發

```
npm install
npm start              # 啟動
npm run demo           # 播放示範
npm run test-mode      # 測試模式：金幣無限、全部解鎖，玩的是存檔副本（deskmates-test.json），不影響正式存檔
npm run install-hooks  # 安裝 Claude Code hooks（設定視窗也有按鈕）
npm run preview -- chars out.png   # 輸出角色/家具預覽圖（chars | lineup | minis | anim | fx | iso）
npm run dist           # 打包成安裝檔 dist/Deskmates-Setup-<版本>.exe
```

啟動參數：`--demo`、`--mode=room|strip`、`--open=settings|guild`。設 `DESKMATES_DEBUG=1` 會印出 hook 事件和視窗 console。

```
src/main/        主程式：actors（角色狀態）、progress（金幣/成就/招募）、fx（隨機事件）、
                 focus（番茄鐘）、activity（前景程式偵測）、server（HTTP）、windows（工作列視窗）、store
src/shared/      主程式和畫面共用：catalog（物品/成就）、sprites（角色）、iso（等角房間與家具）
src/renderer/    strip（工作列）、room（房間 + 編輯器）、settings、guild（夥伴手冊）
```

美術全部用程式畫，沒有外部素材。圖都畫在兩倍細的網格上（角色 64x56、地磚 32x32 細格），不描黑邊，每個部位用自己顏色深一階收邊。角色是兩頭身：大頭、扁臉、豆豆眼。
